About This Site

WorldCup26 is a free, independent website tracking every match of the FIFA World Cup 2026 — the biggest football tournament in history with 48 teams, 104 matches across the United States, Canada and Mexico, running from June 11 to July 19, 2026.

Our goal is simple: fast, accurate, ad-light scores and standings without the bloat of commercial sports aggregators. Single HTML files under 50 KB load in under one second on any mobile connection.

Data Sources

Match data is sourced from OpenFootball, an open-source, community-maintained football data project. All data is in the public domain — free for commercial and non-commercial use.

Scores are updated after each match. There is a 5-minute auto-refresh that pulls the latest data from the OpenFootball GitHub repository.

  • All 104 Group Stage and Knockout matches
  • Goal scorers and assist data where available
  • Half-time scores
  • Group standings auto-calculated from results
  • Top scorers leaderboard

Built With

Zero frameworks. Zero build tools. Pure HTML, CSS and vanilla JavaScript. Hosted free on GitHub Pages.

  • HTML5 + CSS3 + Vanilla JavaScript
  • GitHub Pages (free hosting)
  • OpenFootball JSON API (free, no auth)
  • Google AdSense (to cover hosting costs)
